# Robotics Parallel Spiral — GitHub Pages PWA

This is the installable web-app edition of the Robotics Parallel Spiral pathway.

It is designed to be hosted as a normal HTTPS website, preferably with GitHub Pages.

## Included
- PWA manifest
- service worker
- app icons
- local progress tracker
- offline caching
- no executable launcher

See `PUBLISH_TO_GITHUB_PAGES.md` for deployment instructions.
